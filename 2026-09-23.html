Reporting API

Reporting-Endpoints HTTP ヘッダーと ReportingObserver() API は、Content Security Policy（CSP）違反レポートやクラッシュレポートなど、選択したレポートを指定した URL またはコールバック関数に送信します。 機械翻訳

原文: The Reporting-Endpoints HTTP header and ReportingObserver() API send selected reports, such as Content Security Policy (CSP) violation reports or crash reports, to a nominated URL or callback function.

User agent client hints

Sec-CH-UA HTTP リクエストヘッダーと navigator.userAgentData API は、レスポンスやアプリケーションロジックを変化させるために使用される、ブラウザーおよびプラットフォームの情報を提供します。User agent client hints は user agent strings に似ていますが、よりプライバシーを保護し、安全に解析できます。 機械翻訳

原文: The Sec-CH-UA HTTP request header and the navigator.userAgentData API expose browser and platform information used to vary responses and application logic. User agent client hints are similar to user agent strings but more privacy-preserving and safer to parse.

原文: Partitioned cookies allow you to opt a cookie into partitioned storage, with a separate cookie jar per top-level site. Also known as Cookies Having Independent Partitioned State or CHIPS.
